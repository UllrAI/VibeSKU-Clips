# AI UGC 单条视频生产需求

> 状态：开发基线，2026-09-06。当前阶段只优化一次完成一条视频的体验。

## 1. 产品目标

把一个商品的链接、图片和 Brief，转化为一条可审核、可追溯、可导出的
15 秒 UGC 视频。系统负责商品理解、脚本、可选分镜、视频生成和质量检查；
用户在每个高成本步骤前确认结果。

当前不提供批量计划、数量配置、账号矩阵、后台批次运行或盲目再生成。
先保证一条视频从输入到交付的路径清楚、失败可解释、修改成本可控。

## 2. 核心流程

商品与素材 → 确认商品事实 → 生成并确认脚本 → 可选生成并确认分镜 → 生成视频
→ 质量检查 → 人工选用 → 导出。

| 步骤       | 用户看到什么                            | 用户的主要动作                 |
| ---------- | --------------------------------------- | ------------------------------ |
| 商品       | 链接、图片、Brief、提取出的事实与缺失项 | 修正并确认事实                 |
| 脚本       | 开场、节拍、口播、字幕、发布配文        | 编辑并确认脚本                 |
| 可选分镜   | 每个脚本节拍对应的关键帧                | 修改提示词、单帧重画、确认分镜 |
| 视频       | 成片、质量检查结果、失败原因            | 查看、失败后重试或返回上一步   |
| 审核与导出 | 商品、脚本、模特、语言、市场和成片      | 选用并导出清单                 |

## 3. 输入与资产

- 商品至少提供可读取的 HTTPS 链接或一张商品图。
- 商品事实包含外观、规格、卖点、使用场景、来源和缺失项。
- Brief 包含目标人群、重点卖点、语气、场景、禁用表达和可选指定脚本。
- 可选择无需模特、已有模特或随机生成一位虚构成年模特；模特图片与授权说明单独保存。
- 输出语言与目标市场独立配置，不从界面语言推断。
- 应用内私有图片只保存受保护地址；Worker 调用远端模型前校验归属并签发短期读取地址。

## 4. 生成与质量

- 首期支持人物讲解、场景种草、使用介绍三类模板。
- 时长固定为 15 秒；宽高比可选 9:16 或 16:9，分辨率按供应商能力选择。
- 脚本先校验口播长度，指定脚本过长时提示用户修改，不擅自改写。
- 默认采用一镜到底模式，脚本确认后直接把脚本、商品图和模特图交给视频模型。
- 选择分镜引导时，分镜是检查商品和人物一致性的最后低成本节点。
- 成片检查时长、口播长度、字幕安全区、商品准确性、人物一致性和目标语言表达。
- 生成服务返回的临时文件必须归档到私有对象存储后才能标记完成。

## 5. 状态与失败

- 页面按所选模式展示商品、脚本、可选分镜和视频步骤，不显示虚构百分比或倒计时。
- 长任务在后台继续执行，页面自动读取最新状态。
- 链接不可读、图片无权访问或素材缺失时，商品进入“需要补充”，并说明下一步。
- 可重试错误有明确上限；最后一次失败后，任务与界面立即进入失败状态。
- 失败步骤提供重试和返回上一步，不让终态任务继续显示“生成中”。
- 修改上游步骤时保留来源关系，但不为尚不存在的规模化场景提前设计复杂版本树。

## 6. 导出边界

- 导出成片、封面、字幕、发布配文、披露说明和商品分组清单。
- 清单记录素材编号、商品、变体、语言、市场及归档文件地址。
- 平台不维护挂车链接、库存、发布状态或投放表现。
- “生成完成”和“人工选用”是不同状态，只有用户明确选用的成片进入导出。

## 7. 当前验收重点

- 一张应用内上传的商品图可以被 Worker 正常读取并完成商品解析。
- 无效链接或图片不会造成无限等待，失败会在同一任务中快速、明确地呈现。
- 用户始终知道当前步骤、产物、下一动作及其成本顺序。
- 商品事实、脚本、可选分镜、成片和导出记录可互相追溯。
- 中英文界面一致，不混用界面语言与成片语言。
- lint、类型检查、逻辑测试和生产构建通过。

批量生产、并发规划、多版本自动扩展和账号维度导出，只有在单条流程经过真实使用验证后才重新评估，不在当前数据模型中保留占位实现。
