# AI UGC 视频生产平台需求

> 状态：需求讨论稿，2026-09-05。用于范围评审，暂不细拆接口、数据库和开发任务。
> 业务依据：[项目建设方案](../%23%20AI%20UGC%20视频智能生产平台建设方案.md)。
> 开发基础：[UllrAI SaaS Starter](https://github.com/ullrai/saas-starter)。

## 1. 产品目标与范围

建设一套面向 TikTok 账号矩阵的视频生产平台，将商品资料转化为适配不同语言和市场的 15 秒 UGC 视频。用户主要负责提交创作要求和集中审核选用，系统连续完成商品理解、脚本、视听生成、剪辑与质量检查。

交付范围包含可部署的 Web 产品、三类生产模板、可复用内容资产、样片与试运行记录，以及操作文档、培训和交接。

平台负责素材生产与商品对应清单。账号登录、内容发布、实际挂车和运营效果观察由运营通过既有工具完成；账号标签仅用于内容分组与导出。播放量和成交效果不作为平台生产能力的验收承诺。

## 2. 开发基础

计划基于 SaaS Starter 开发，优先复用其通用基础能力，新增视频生产业务。

根据上游 README，基础项目提供 Next.js 与 TypeScript、登录认证、PostgreSQL 与 Drizzle、UI 组件、文件上传、界面国际化及测试工具等能力。具体复用方式在开发阶段结合选定版本确认。

| 类别 | 本项目处理原则 |
|---|---|
| 登录、页面框架、表单、数据库、文件上传 | 优先复用基础项目，按业务需要适配 |
| 商品、模特、脚本、生产任务、审核、导出 | 本项目新增的核心业务能力 |
| 视频生成、剪辑、质检、长时间任务执行 | 按实际生成服务能力设计与接入 |
| 支付订阅、博客、开发者 API 等已有功能 | 不因模板自带而自动纳入产品需求，按实际需要启用 |

界面国际化与视频内容多语言是两个独立需求，模板的界面国际化不能替代脚本、口播和字幕的本地化生产能力。

本阶段仅整理需求文档，不引入模板代码或确定具体生成服务。

## 3. 核心使用流程

提交商品资料与 Brief → 设置语言、市场、可选模特及数量 → 查看总数与预计消耗 → 自动生产与质检 → 成片审核 → 选用导出或再生成。

| 工作区域 | 用户主要操作 |
|---|---|
| 创建任务 | 导入商品，填写 Brief，选择模板、语言、市场和模特，配置数量并提交 |
| 生产进度 | 查看单条与批次进度，补充缺失信息，处理失败项，取消未执行任务 |
| 成片工作台 | 预览比较、核对商品、标记选用、分组导出、调整与再生成 |

默认不要求用户逐条确认商品分析、脚本或分镜；有明确创意要求时支持指定脚本，或主动开启脚本预览与编辑。

## 4. 核心需求模块

### 4.1 商品与创作要求

- 支持商品链接，或商品图片 + Brief，也可同时提供链接和图片。
- 支持链接列表或表格批量导入，图片及 Brief 按商品关联。
- 提取商品外观、规格、卖点和使用场景；商品事实以可靠资料为准。
- Brief 可包含目标人群、重点卖点、风格、场景、禁用表达和指定脚本，未指定的创意细节由系统补充。
- 区分商品变体、参考链接和目标市场商品链接，避免素材关联错误商品。
- 链接不可读、资料冲突或关键信息缺失时，仅暂停相关商品并提示补充。

### 4.2 模特与素材资产

- 支持上传获授权的模特图片，或根据描述生成虚构成年模特供选择。
- 模特可选；未指定时采用产品展示或适配的默认人物方案。
- 支持按商品或内容组指定模特，并在后续视频中复用。
- 声音由系统匹配或使用配置资源；模特图片不代表真人声音复刻授权。
- 沉淀商品、模特图片、脚本、声音和合格镜头，记录素材来源与授权范围。

### 4.3 脚本与多语言创作

- 输出语言与目标市场独立配置，适配当地用词、语气、声音、生活场景及商品资料。
- 生成目标语言脚本、口播、字幕和发布配文。
- 首期包含人物讲解、场景种草、使用介绍三类模板。
- 支持自动脚本、用户指定或编辑脚本，以及不同开场、卖点角度和叙述结构。
- 同脚本多视频保持既定口播和内容结构，允许画面、表演或场景变化。
- 跨商品、跨语言复用创意时重新适配事实与台词，并保存独立脚本版本。

中文、英语、日语、韩语、葡萄牙语、西班牙语为方案中的覆盖方向；首批交付语种及市场组合在启动时确认。

### 4.4 单条与批量生产

- 支持多商品生产，以及同商品同脚本多视频、多脚本多视频。
- 支持按模特、语言市场和账号内容风格分组生产，共用设置可逐项覆盖。
- 提交前展示总视频数与预计消耗，按明确配置执行，不自动进行所有维度的全排列。
- 展示批次与单项进度，单项失败可独立处理，系统自动重试须有上限。
- 支持取消未执行任务，以及基于优选商品、脚本和模特设置追加视频。
- 区分系统失败重试和用户主动再生成，两者均记录消耗并纳入预算管理。

### 4.5 视频生成与质量保障

- 连续完成视听生成、配音、字幕、音乐、剪辑和自动检查。
- 成片规格为 15 秒、9:16、1080×1920，包含完整开场、商品展示与结尾。
- 控制口播长度和字幕同步，不生硬加速或截断对白；锁定脚本超时则提示精简，不擅自改写。
- 结合 AI 生成与授权实拍素材，实际效果或复杂操作演示须有依据。
- 检查商品准确性、人物参考一致性、目标语言表达、时长和音画质量。
- 字幕及重点信息避开平台按钮与挂车区域，不伪造可点击购物组件。
- 按市场配置内容规则和必要披露，不虚构消费者体验或商品效果。

### 4.6 审核与再生成

- 按商品、语言、脚本和视频版本分组预览比较，可附账号标签。
- 支持标记选用、待定、不采用，并查看商品及脚本对应关系。
- 提示批次内与已导出素材中的重复或高度相似内容，辅助人工选用。
- 支持保持脚本重新生成画面，或修改 Brief、模特、脚本后再生成。
- 字幕等轻量修改直接重新合成；镜头可替换时局部处理，需整条重做时明确提示。
- 调整仅影响选定范围，原结果保留，新旧版本可追溯。

### 4.7 导出与生产统计

- 按商品或账号标签分组下载选中视频。
- 随附封面、字幕、目标语言发布配文、必要披露说明及商品对应清单。
- 清单包含素材编号、商品名称、变体和目标市场商品链接。
- 缺少目标商品链接时标记“待匹配商品”，不自动视为可挂车素材。
- 使用促销信息时记录条件与有效期，过期素材提示复核。
- 保留导出记录和资源消耗，支持统计合格产出、人工处理时间、生产周期与单片成本。

## 5. 关键业务规则

| 规则 | 说明 |
|---|---|
| 数量按明确计划汇总 | 总数为各配置项下各脚本的视频数量之和，不隐式增加模特、场景或语言组合 |
| 商品事实优先 | Brief 约束创意方向，不能覆盖可靠商品事实；不同市场、变体不能串用资料 |
| 局部异常独立处理 | 缺资料、失败和重试尽量限定到相关商品或视频，不阻断正常任务 |
| 脚本与结果保留版本 | 锁定脚本不擅改；修改、本地化、再生成均保留来源关系 |
| 生成、选用与商品匹配分开 | 生成成功不等于审核选用，选用也不代表已核对挂车商品 |
| 重试与追加分开统计 | 重试增加尝试及费用，不自动扩大用户要求的目标视频数量 |
| 相似提示辅助决策 | 不代表平台原创性认定，也不保证推荐或分发效果 |

典型数量示例：20 商品 × 1 脚本 × 1 视频 = 20 条；1 商品 × 3 脚本 × 2 视频 = 6 条；同一脚本分别为两位模特各生成 3 条 = 6 条。

## 6. 实施与验收方向

沿用建设方案的三个阶段，暂不细拆工期与开发任务：

| 阶段 | 主要成果 |
|---|---|
| 样片验证 | 用真实商品验证输入、模特、三类模板、约定语种和成片规格，确认质量与成本基线 |
| 产品建设 | 完成上述模块，打通自动生产、批量、审核、再生成和导出闭环 |
| 试运行与交接 | 验证典型批量场景、商品对应、失败处理与生产成本，完成部署、文档和培训 |

验收关注功能完整、成片合格、数量准确、不串商品、版本可追溯、多语言自然、导出清单准确，以及效率和成本可衡量。

建设方案中的 6—8 周为建议周期；最终任务合格率 85%、经常性人工处理时间降低 50% 为试点优化目标。具体计划、样本、计算口径和阈值须在样片验证后确认。

## 7. 待确认事项

| 主题 | 需要明确的内容 |
|---|---|
| 首批业务范围 | 商品品类与来源网站、语言市场组合、代表样品及语言审核人员 |
| 用户与使用方式 | 内部团队还是对外 SaaS，登录方式、角色权限、是否需要团队隔离与收费 |
| 生产规模与费用 | 批次上限、并发与日生产量、预计消耗展示方式、预算及重试上限 |
| 服务与部署 | 生成服务选择、部署环境、费用承担方、素材保存期限与运维责任 |
| 交互边界 | 脚本预览是否等待确认、自带脚本默认策略、局部修改支持范围 |
| 质量与交付标准 | 时长容差、人物一致性、质检阻断规则、相似提示标准、配套文件格式与未匹配商品导出规则 |
| 验收口径 | 样本及合格标准、人工耗时和成本统计方式、目标是否转为验收门槛 |

本阶段不预设上述问题的答案，也不将模板已有的商业化功能视为新增业务承诺。
