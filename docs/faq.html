一、费用与开源

ClipForge 真的免费吗?

免费。开源(AGPL-3.0)、无水印、不限条数:免费快剪链路 = 免费图库素材 + 免费微软 Edge TTS 配音 + 本地 FFmpeg 合成,全程 ¥0 出 1080p 竖屏整片;只有写脚本需要一个 LLM Key(DeepSeek 单次约 ¥0.001),费用付给模型平台。0 元链路的完整拆解见免费 AI 视频生成。

AI 生成一条视频要多少钱?

按秒计费、标在选项上:九宫格分镜一次生图约 ¥1.3;Seedance 2.5 一键整片 12 秒实测约 ¥26;换 Mini 档约 ¥0.28/秒。脚本免费生成,确认后一次点击才开始计费,费用按量付给你选的模型平台。

为什么要自带 Key(BYOK)?

因为 ClipForge 是开源工具而不是 SaaS:软件永远免费,AI 用量直接付给你自己选的模型平台(Atlas Cloud、火山方舟、fal.ai、OpenAI、DeepSeek 等),ClipForge 不加价不抽成。好处是价格透明、不被套餐绑架,数据也全在本机。

免费快剪和 AI 生成成片怎么选?

二、上手

不会剪辑能用吗?

能,这是默认体验。小白模式全托管:丢商品图或说一句话主题 → 看一眼脚本 → 直达成片,全程一张进度卡,不见分镜不见术语;想要专业控制再切导演模式,解锁分镜编辑、判官团、18 款运镜预设、九宫格、一键整片、变体矩阵。

需要真人出镜吗?

不需要。带货形式四选:智能推荐 / 真人口播 / 情景短剧 / 图文混剪——选真人口播时由 AI 生成素人形象对镜口播,免费档则是无真人脸的图文混剪,全程不用自己出镜或拍摄。

支持英文视频吗?

支持。界面与成片都是中英双语:界面可切英文,同一条流程直接产出英文口播成片,适合 TikTok 等出海场景。

怎么安装部署?

三种方式任选:下载 Windows / macOS 桌面版双击即用;Docker 一行命令拉起镜像 ghcr.io/xixihhhh/clipforge;或克隆源码运行。详细步骤见使用手册第一节。

三、质量

商品会变形吗?

不会。image-to-image 锁定商品原图,换背景、打光都不改商品本体,避免「货不对板」带来的转化损失与售后风险。

生成的视频会像静图拼接吗?

AI 生成成片档不会:走图生视频质量主路,每个分镜都是真动态镜头,链式首尾帧让转场在镜头内生成、拼接不跳切。免费快剪档是真实素材混剪,定位是 0 元跑量,追求质感请选 AI 档。

AI 生成的人脸会不会一眼假?

有两层约束:一是素人真实感规则(口语台词、生活痕迹背景、行为节拍),不出「网红假脸」;二是主播库四视图定妆照——正/侧/背/特写一次生成保证同一个人,之后生成都拿定妆照当身份锚,跨镜头、跨条视频不换脸。

有现成模板吗?

有。391 款成片模板,按商品自动推荐;导演模式的高级新建里可对品类、人群、平台、模板逐项调整。

五、技术

数据存在哪里?

全在本机:项目数据存本地 SQLite,素材与成片存本地文件,不上传任何服务器;Docker 自部署同理,数据留在你自己的机器上。

支持哪些 AI 模型平台?

一个接口聚合 7 大平台 30+ 模型:Atlas Cloud(推荐,一个 Key 覆盖脚本+生图+视频+配音)、火山方舟、fal.ai、OpenAI、DeepSeek 等,配置方法见使用手册第三节。

生成失败会白扣费吗?

不会白扣。付费任务走两阶段任务表:已提交的云端任务记录在案,可在素材页恢复领取结果,不会因为页面关闭或中断而重复提交扣费;免费链路则可以随便重试。

怎么自动化批量出片?

三个入口:MCP Server(在 Claude / Cursor 等 agent 里一句话出片)、CLI(脚本化出片,配 cron 就是全自动日更机)、agent Skill。项目有 986 个单元测试保障链路稳定。
