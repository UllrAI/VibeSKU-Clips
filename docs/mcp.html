一、什么是 ClipForge MCP:把出片流水线变成 agent 工具

ClipForge 是开源的 AI 短视频工具(带货为主场景),它把整条「一句话 → 脚本 → 配画面 → 配音字幕 → FFmpeg 合成竖屏成片」流水线通过 MCP(Model Context Protocol)Server 暴露成标准工具——任何 MCP 客户端(Claude Desktop、Claude Code、Cursor 等)注册之后,agent 就能直接调用「视频生成」这个能力,不用你打开任何界面。

  • 形态:仓库内 mcp/clipforge-mcp.mjs,一个 stdio MCP Server,是 ClipForge HTTP API 的薄封装——复用实例里的全部编排(脚本引擎 / 免费素材 / 免费 Edge TTS / FFmpeg 合成),运行前需先启动一个 ClipForge 实例;npm 包形态 clipforge-mcp 也已在仓库备好(发布后可 npx 零安装接入)。
  • 费用:素材与配音免 Key、¥0;只有「生成脚本」需要一个 OpenAI 兼容 LLM Key(如 DeepSeek,单次约 ¥0.001)。
  • 产出:1080p 竖屏(也可 16:9 / 1:1)无水印 mp4,自带字幕,AIGC 合规标识可开——发布前怎么不踩限流坑,见AI 视频合规发布指南。

二、三步接入:从零到 agent 一句话成片

第 1 步:启动一个 ClipForge 实例

docker run -d -p 3000:3000 -v clipforge-data:/data ghcr.io/xixihhhh/clipforge
# 或源码:git clone https://github.com/xixihhhh/clipforge.git && cd clipforge && pnpm install && pnpm dev

MCP Server 默认指向 http://localhost:3000(可用 CLIPFORGE_BASE_URL 改)。

第 2 步:在 MCP 客户端注册

Claude Desktop(claude_desktop_config.json)或 Cursor(~/.cursor/mcp.json)加入:

{
  "mcpServers": {
    "clipforge": {
      "command": "node",
      "args": ["/绝对路径/clipforge/mcp/clipforge-mcp.mjs"],
      "env": {
        "CLIPFORGE_BASE_URL": "http://localhost:3000",
        "CLIPFORGE_LLM_BASE_URL": "https://api.atlascloud.ai/v1",
        "CLIPFORGE_LLM_API_KEY": "sk-...",
        "CLIPFORGE_LLM_MODEL": "deepseek-ai/deepseek-v4-pro"
      }
    }
  }
}

Claude Code 一条命令:

claude mcp add clipforge -- node /绝对路径/clipforge/mcp/clipforge-mcp.mjs

第 3 步:对话里直接说

用 clipforge 做一条关于「在家如何泡手冲咖啡」的竖屏短视频

agent 会调用 clipforge_create_video,几十秒后返回可下载的 mp4 地址。带货场景则先贴商品链接——clipforge_ingest_product 自动抓标题 / 价格 / 主图并建好项目,接着出脚本、出片一气呵成。

本地想直接试 Server 本体:仓库根目录 pnpm mcp(等价于 node mcp/clipforge-mcp.mjs,stdio 模式)。

三、MCP 工具清单:从建项目到发布把关

共 28 个 MCP 工具覆盖出片、原片剪辑与专业交付全流程,核心几个:

工具做什么需要 LLM Key
clipforge_create_video一句话 → 脚本 → 免费配画面 → 免费配音+字幕 → 合成竖屏成片,返回可下载 mp4 地址✅
clipforge_ingest_product贴商品链接 → 抓标题/价/图 → 一键建带货项目—
clipforge_generate_script只生成旁白分镜脚本(含英文素材检索词)✅
clipforge_search_stock从免费可商用素材库检索画面(免 Key)—
clipforge_compose为已有脚本+素材的项目合成出片,可开卡拉OK字幕 / 商品卡 / AI 合规标识 / 购买 CTA / BGM 等带货增强—
clipforge_trends拉热榜选题(国内榜 / Google Trends),不知道做什么先问它—
clipforge_list_voices列出免费 Edge TTS 多语言音色(中/英/日/韩/西)—
clipforge_get_video查询项目最新合成结果(状态/下载地址),轮询异步产物—
clipforge_transcript_inspect分页读取原片逐词稿、稳定词 ID 与当前剪辑版本—
clipforge_transcript_edit预演或应用剪辑计划;默认只返回 diff,明确确认后才渲染新版本—
clipforge_timeline_export导出 OTIO / EDL / CSV 专业时间线;不写库、不含本机绝对路径—

出片之后还有交付把关工具:发布门禁 clipforge_gate(脚本就绪+质检+素材授权一键体检,fail 别交付)、成片质检 clipforge_qc(黑屏/静音/响度)、成片速览 clipforge_contact_sheet(agent 看图自检)、素材授权清单 clipforge_credits、平台导出 clipforge_export_platform 等——agent 不只是能出片,还能自己检查完再交给你。完整清单见 mcp/README。

四、CLI 脚本化出片:一行命令一条片

不走 agent 也可以纯命令行(先启动实例、设好 CLIPFORGE_LLM_* 环境变量):

npm run cli -- trends                              # 不知道做什么?先拉热搜选题
npm run cli -- create --topic "在家手冲咖啡" --quality hd --bgm   # 一句话出片,回填 videoUrl
npm run cli -- qc --project <id>                   # 成片质检(黑屏/静音/响度)
npm run cli -- gate --project <id> --strict        # 发布门禁,拦截时退出码 2(可接 CI)
npm run cli -- transcript --project <id> --media <mediaId>  # 检查逐词稿与版本
npm run cli -- transcript-edit --project <id> --media <mediaId> --plan edit.json --revision 0 --operation edit-001  # 默认预演;--apply 才执行
npm run cli -- timeline --project <id> --media <mediaId> --plan edit.json --format otio --out edit.otio  # 导出可编辑时间线
npm run cli -- --help                              # 全部命令与参数

等价写法 node bin/clipforge.mjs create --topic "..."。还有 import(自带稿子出片)、dub(换语种译制出海)、cover(封面图)、carousel(小红书图文卡)等子命令,全部可编排进脚本。

五、cron 定时 + 按人设选题 = 全自动日更机

「AI agent 短视频日更」最省事的形态其实是一行 crontab:trends 拉热榜、create 出片,接上 cron 每天固定时间产出一条待发成片:

crontab -e   # 加入下面一行(路径与环境变量换成你的):每天 9 点从国内热榜拿榜一出一条
0 9 * * * cd /path/to/clipforge && TOPIC=$(node bin/clipforge.mjs trends --json | python3 -c "import json,sys;print(json.load(sys.stdin)['topics'][0]['title'])") && node bin/clipforge.mjs create --topic "$TOPIC" --bgm >> daily.log 2>&1

不想碰终端?网页版是同一逻辑:工作台的「日更 · 按人设选题」填几个人设关键词,自动按人设挑选题、预填一句话成片——cron 负责准时,人设负责选题,你只负责最后点发布。

六、批量出片:大促 10 个商品排队

大促备货不用一条条来:导演模式的批量出片页把多个商品(如 10 个)一键排队,自动逐条走完「脚本 → 画面 → 配音 → 合成」,产出后统一查收——自动化带货视频的产能瓶颈从「人剪多快」变成「机器排多长的队」。

七、Agent Skill:教会 agent「什么时候用哪个工具」

MCP 给了 agent 可调用的工具,Skill 则教它何时、如何组合使用(Claude Code / Cursor / Copilot / Windsurf 通用的 SKILL.md 约定):

  • clipforge-video skill:把整条出片流水线(脚本 → 素材 → 配音 → 字幕 → 合成 → 质检门禁)教给编程助手,自然语言驱动全程;
  • script-judges 判官团 skill:独立可用的四判官(节奏 / 口语 / 新鲜感 / 结构)在花生成费之前逐句撕台词并给等长重写——「大家好,今天给大家推荐」这种一眼广告腔活不过第一轮;
  • 装法任选:npx skills add xixihhhh/clipforge 一条命令;Claude Code 里 /plugin marketplace add xixihhhh/clipforge 装 skill + MCP 二合一。
